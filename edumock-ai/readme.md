# 🎓 EduMock AI - Intelligent Mock Testing Platform

A production-ready, secure, and **100% free** online mock testing platform powered by **Hugging Face AI**. Built for students, teachers, and administrators with enterprise-grade security and zero infrastructure costs.

## ✨ Features

### For Students
- ✅ **Self-registration** and secure login
- 🎯 **10-question mock tests** with exact questions from PDFs
- ⏱️ **Live countdown timer** with auto-submit
- 📊 **Instant results** with AI-generated explanations
- 💬 **AI Navigation Assistant** (bottom-right widget)
- 📈 **Performance tracking** and test history

### For Teachers
- 👨‍🏫 **Manual account creation** by admin (no self-registration)
- 📚 **Student management** and test assignment
- 📊 **Class analytics** and performance heatmaps
- 📈 **Progress monitoring** for individual students

### For Admins
- 🔐 **Secure user management** (create teachers, manage students)
- 📄 **PDF ingestion system** (RAG-powered question extraction)
- 🤖 **AI model configuration** via Hugging Face
- ⚙️ **Full system oversight** and audit logs
